Featured Projects

Wildfire Early Warning System

  • Architected a predictive ML system for indigenous forest communities to forecast wildfire risks 72 hours in advance.
  • Integrated and preprocessed multimodal geospatial data, including NASA active fire detections (VIIRS/MODIS), CHIRPS rainfall, and ERA5 wind models.
  • Developed an XGBoost classification pipeline utilizing walk-forward temporal cross-validation, optimized via Optuna to achieve an 85% recall rate.
  • Deployed an interactive Folium web dashboard with SHAP TreeExplainer for per-district risk explainability and automated bilingual alerting.

Oil Palm Tree Health Detection System

  • Developed an automated detection system for oil palm tree health monitoring using UAV imagery, achieving 94.7% mAP.
  • Performed tree detection, counting, and multiclass health classification (Healthy, Yellowing, Small, Dead) using YOLOv8 and YOLOv12.
  • Deployed a web application using Streamlit for real-time field monitoring by agricultural teams.
  • Published: IEEE AGERS 2025.

Real-Time Crisis Recognition & Response System

Conflict-Induced Food Crisis Prediction

  • Developed a machine learning system to forecast IPC Phase 3+ food crises 90 days ahead using conflict, climate, and historical food security data.
  • Applied data fusion, feature engineering, and temporal modeling to capture complex crisis patterns across 14 African countries.
  • Implemented a hyperparameter-tuned XGBoost model, integrated with SHAP explainability for accurate, interpretable humanitarian predictions.

Forensic Fake Image Detection

  • Built a deep learning pipeline to detect AI-generated images using pixel-level forensic features and frequency domain analysis (FFT).
  • Utilized CNNs and transfer learning (EfficientNetB0) to improve classification performance, achieving a 97.2% recall rate.
  • Incorporated explainability techniques (Grad-CAM) to validate that the model focused on meaningful visual texture artifacts rather than semantic biases.
