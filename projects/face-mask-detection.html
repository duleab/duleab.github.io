Project Overview

Safety Compliance Monitoring

This project implements a robust real-time face mask detection system designed to integrate with existing CCTV infrastructure. The pipeline identifies faces in a frame and classifies them into three categories: wearing a mask correctly, incorrectly, or not wearing a mask at all.

Technical Approach: A two-stage architecture first locates faces using a pre-trained face detection model, then passes the cropped regions to a custom Convolutional Neural Network (CNN) trained on over 10,000 diverse images.

System Components

Technical Implementation

The system operates via a streamlined sequence of modules for maximum frame-rate efficiency:

  • Face Detection: Identifies regions of interest regardless of scale or partial occlusion.
  • Mask Classification: A lightweight TensorFlow CNN evaluates each face.
  • Alert & Visualization: Renders color-coded bounding boxes and triggers alerts for non-compliance.
