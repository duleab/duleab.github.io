Problem Statement

Financial Inclusion Through Alternative Credit Scoring

Traditional credit scoring models rely heavily on credit bureau data, which excludes millions of potential borrowers who lack formal credit history. This project develops an alternative approach using the Xente Challenge dataset — leveraging transaction patterns, mobile money usage, and behavioral signals to assess creditworthiness for the underbanked.

Feature Engineering

34 Engineered Features from Raw Transactions

Feature engineering was the core of this project. From 3.9M+ raw transactions, four categories of predictive signals were extracted:

  1. 1

    Temporal Features

    Transaction frequency, seasonality patterns, time-between-payments, and account age metrics.

  2. 2

    Aggregation Features

    Rolling averages, cumulative statistics, and balance volatility over 7/30/90 day windows.

  3. 3

    Behavioural Features

    Payment channel preferences, usage consistency, device patterns, and geographic signals.

  4. 4

    Risk Indicators

    Transaction anomalies, overdraft frequency, provider relationship stability.
