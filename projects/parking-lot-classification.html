Project Overview

Automated Space Tracking

This project implements a smart parking system aimed at helping drivers find spaces efficiently. By analyzing static CCTV feeds of parking lots, the system maps out designated spaces and continually updates their occupancy status using deep learning.

System Optimization: To ensure fast processing on edge devices, the system uses static coordinate mapping for space locations and evaluates a lightweight Convolutional Neural Network (CNN) only on cropped image patches corresponding to individual parking spots.

Technical Pipeline

System Architecture

The implementation is divided into independent modules for scalability:

  • Space Segmentation: Pre-defining polygon regions for each parking spot to isolate the areas of interest.
  • CNN Classification: A TensorFlow model trained to classify image patches into Empty or Occupied classes, robust to lighting variations.
  • Tracking & State Management: Buffering predictions temporally to prevent flickering when cars are maneuvering.
  • Visualization: Drawing intuitive red/green overlays over the video feed with real-time capacity counters.
