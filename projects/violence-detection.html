Real-Time Crisis Recognition & Response System

A multimodal AI framework combining YOLO object detection, 17-keypoint pose estimation, and behavioral scoring to classify protest violence in real time — generating timestamped crisis alerts for law enforcement situational awareness.

System Architecture

Multimodal Violence Detection Framework

Unlike single-frame classifiers, this system processes sequences of video frames to capture the temporal motion patterns that uniquely characterize violent acts. It combines a YOLO-based detector for person localization, a 17-keypoint pose estimation module for skeletal tracking, and a behavioral scoring algorithm that analyzes joint angles and hand-object proximity to classify aggression level.

Key Insight: Analyzing joint velocity and arm trajectory over a sliding window — rather than static pose snapshots — dramatically reduces false positives from non-violent poses that visually resemble aggression.

Detection Pipeline

Four-Stage Processing Pipeline

  1. 1

    Person Detection (YOLO)

    Each video frame is processed by a YOLO model to detect and localize all persons in the scene with bounding boxes.

  2. 2

    17-Keypoint Pose Estimation

    For each detected person, a pose estimation model extracts 17 anatomical keypoints (shoulders, elbows, wrists, hips, knees, etc.) to build a full skeletal representation.

  3. 3

    Behavioral Scoring

    Joint angles, limb velocities, and hand-object proximity are computed across frames. A behavioral scoring model classifies the sequence as Throwing, Fighting, or Normal.

  4. 4

    Alert Generation

    On a positive classification, the system generates a timestamped crisis alert with annotated keyframes, providing law enforcement with precise situational awareness.

Violence Classes

Three Behavioural Categories

  • Physical Fighting — Punching, kicking, brawling, wrestling identified through rapid limb movement and close inter-person proximity.
  • Object Throwing — Any thrown projectile directed toward people or property, detected via arm-arc trajectory analysis.
  • Non-violent — Normal movement baseline (walking, standing, running) used as a negative class to reduce false alarms.
