01 — Overview

Real-time crisis intelligence

This system provides real-time detection and classification of crisis events from multilingual social media and news sources. Designed for emergency response coordinators, it aggregates raw posts, classifies crisis type with high confidence, clusters related events geographically, and displays them on an interactive map.

Multi-Source Ingestion

Collects from Reddit, Telegram, BMKG RSS feeds, and news aggregators in real-time.

XLM-RoBERTa Classifier

Fine-tuned multilingual transformer achieving 96.7% accuracy across 7 crisis categories.

Geo-Clustering

SBERT embeddings + DBSCAN clustering to group related events geographically.

Credibility Scoring

Multi-signal credibility assessment to filter noise and prioritize verified reports.

SHAP Explainability

Word-level attribution showing exactly which tokens drive each classification decision.

Interactive Dashboard

Folium-powered map with GeoJSON export, event timelines, and cluster visualization.

Target Region: Indonesia

With global capability via the multilingual XLM-RoBERTa backbone. Data sources include BMKG (Indonesia Meteorological Agency), USGS Earthquake API, and NASA FIRMS fire detection.

04 — Pipeline

Step by step

Run notebooks in order. Each saves outputs that the next one consumes.

01

Data Collection

NB01

Collect live posts from Reddit, BMKG, RSS → posts_unified.csv

Connects to Reddit API, BMKG RSS feeds, Telegram channels, and news RSS sources to collect real-time crisis-related posts. Handles rate limiting and deduplication.

Output: data/raw/posts_unified.csv
1B

Bulk Dataset Loader

NB01B ONE-TIME

Load 28K+ labeled training data from HumAID, CrisisLex, DisasterTweets → training_data.csv

Aggregates and balances data from multiple crisis NLP datasets. Includes enrichment scripts for earthquake (69→3,966) and fire (379→5,000) classes using USGS and NASA FIRMS data.

Output: data/external/training_data.csv (28,415 samples)
02

Preprocessing

NB02

Text cleaning, geo-resolution, timestamp normalization → posts_processed.csv

Cleans HTML artifacts, normalizes unicode, extracts and resolves location mentions to lat/lng coordinates, and standardizes timestamps to UTC.

Output: data/processed/posts_processed.csv
03

Feature Engineering

NB03

Credibility feature engineering — source trust, urgency signals, named entities

Extracts features for downstream credibility scoring: source reliability score, urgency keyword density, named entity counts, hashtag patterns, and post metadata signals.

Output: Features appended to processed CSV
KEY STEP
04

Event Classification

NB04

XLM-RoBERTa fine-tuning & classification → classified_events.csv + model weights

Fine-tunes XLM-RoBERTa-base on the 28K balanced dataset. Uses AdamW optimizer with 2e-5 learning rate, linear warmup, and early stopping. Saves best checkpoint by validation loss.

Outputs:
data/processed/classified_events.csv
models/crisis_classifier/model_weights/
models/crisis_classifier/tokenizer/
05

Credibility & Clustering

NB05

DBSCAN event clustering with composite distance → clustered_events.csv

Generates SBERT embeddings, computes composite distance (semantic + geographic), runs DBSCAN to cluster co-occurring events, and applies multi-signal credibility scoring.

Output: data/processed/clustered_events.csv
06

Evaluation & Explainability

NB06

SHAP word attribution + full classification report + confusion matrix

Generates per-class precision/recall/F1, confusion matrix visualization, and SHAP PartitionExplainer attributions for individual predictions. Saves all figures to outputs/.

Output: outputs/figures/ (confusion_matrix.png, shap_*.png, training_curves.png)
07

Dashboard & Map

NB07

Interactive Folium map with crisis markers, cluster overlays, and timeline → interactive_crisis_map.html

Creates a Folium interactive map with color-coded markers per crisis type, cluster circle overlays, popups with post details and credibility scores. Exports GeoJSON for external tools.

Outputs:
outputs/maps/interactive_crisis_map.html
outputs/events_dashboard.geojson
